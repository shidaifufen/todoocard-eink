土豆片卡片工坊（便携版）
=====================================

把这张六色墨水屏（TodooCard / T3，528×792）变成桌面上的小看板：
每日总结、待办、天气、月历、每日一句、诗词、时间进度、倒计时、照片、Bing 壁纸……

不用装 Python、不用装任何运行库、不用联网装依赖。
整个文件夹解压出来，双击里面的「土豆片卡片工坊.exe」就能用。

【怎么开始】

1. 把压缩包解压到任意位置（桌面、D 盘、U 盘都行）
2. 双击「土豆片卡片工坊.exe」
   第一次启动会慢几秒（Windows 在扫描新程序），之后就快了
3. 浏览器会自动打开 http://127.0.0.1:8199/card.html
   没自动打开的话，手动把上面这个地址粘进浏览器
4. 左边选模板，右边改内容，预览就是卡片上会显示的样子

【关掉就是这个】

那个黑窗口就是服务本身。关掉窗口 = 停止服务，网页会打不开；
再双击一次图标就重新跑起来。

【东西都存在哪】

全在这个文件夹里：

    data\card.json          你的设置、待办、计划
    data\cards\             生成的卡片图
    data\bing\              Bing 壁纸缓存
    data\poetry / *.json    诗词赏析缓存等

整个文件夹拷到 U 盘或者另一台电脑，数据跟着走。
想清空重来：关掉程序，删掉 data\ 文件夹即可（程序会自己重建）。

【怎么更新到新版本】

1. 关掉程序
2. 把新版本的压缩包解压，覆盖到同一个文件夹
3. 双击启动

data\ 文件夹不会被覆盖，你的设置、待办、历史都还在。

【怎么"卸载"】

这就是便携版的好处：关掉程序，把整个文件夹删掉就完事了，
不会往系统里留任何东西（除了下面说的浏览器缓存）。

【连接卡片（要用到才需要）】

1. 先在系统蓝牙里配对卡片：Windows 设置 → 蓝牙 → 添加设备 → 选
   TodooCard（或 FFFF 开头的那台），配对时可能要长按卡片背面按钮 5 秒
2. 网页 →「设备与配对」→「扫描设备」，能看到卡片就点「用这台」
3. 发图前先关掉 TodooCam 等其它连着卡片的程序
4. 点「发送这个模板」就开始推了，一次 1~2 分钟

   发送时会自己等卡片广播，**不用按按键唤醒**；看到广播但没连上会自动
   重试一轮。传完还要等卡片"显影确认"，等不到会提示"已写入，可能已刷新"。

【天气城市怎么设】

「天气看板」/「每日总结」右侧 → 城市框填名字（比如 深圳）→ 点「按城市更新位置」，
程序会自己把名字换成经纬度并刷新预览。联网时用 Open-Meteo 的在线查询，
没网就退回内置的 206 个城市。查不准就直接手改下面的经纬度，再点「保存」。

【要不要联网】

程序本身完全离线：不装 Python、不下载依赖，解压即可运行。

这些卡片内容需要联网才有真数据（没网会显示兜底内容或"获取失败"，不会崩）：
    · 天气 / 空气质量（Open-Meteo）
    · 每日一句（hitokoto）
    · 每日诗词（今日诗词）
    · Bing 壁纸
    · AI 生图 / 赏析（Pollinations，或你自己的 API Key）
每日待办、月历、时间进度、倒计时、照片卡 完全离线可用。

【常见问题】

· 发送失败 / 想反馈问题 —— 打开发送日志 data\app.log（就在本文件夹的 data\ 里），
  里面记着发送的每一步：扫到没扫到卡片、连上没连上、卡在哪一步。把它发出来最快。
· 网页打不开 —— 先看黑窗口还在不在；如果窗口里提示端口被占用，它会告诉你
  改用了哪个端口，按提示的地址打开即可（也可以设环境变量 PORT 指定 8200 之类）。
· 双击没反应/一闪而过 —— 从资源管理器地址栏输入 cmd 回车，把 exe 拖进黑窗口
  回车运行，能看到详细报错；把报错发出来即可。
· 卡片扫不到 —— 卡片要开机、要在配对窗口里、别被别的 App 连着。
· 杀毒软件报警 —— exe 是 PyInstaller 打的包，容易被启发式误报；加信任即可。
· 想换端口 —— 在系统环境变量里加 PORT=8200 再启动。
