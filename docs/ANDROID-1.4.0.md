# Android 1.4.0（2026-11-24）

- 天气看板与色块天气恢复 WMO 天气图示；天气看板恢复未来六小时温度曲线，色块天气保持无曲线版式。天气与 AQI 并发获取。
- 首先展示已保存内容，后台按缓存时效更新。天气缓存 20 分钟，句子和诗词缓存一天；支持主动刷新，同一批并发请求复用结果。获取失败保留原内容，手动修改不被后台响应覆盖。
- 恢复字号、行距、元素间距控制，工作台支持滚动，避免小屏操作区域被挤掉。
- 每日诗词支持手动获取 AI 赏析，默认尝试免配置在线服务，也可配置自己的文本 API。
- 自定义卡片支持添加、删除、开关、上移、下移已有元素，调整字号、对齐及图片/二维码高度；支持天气、诗词、每日一句、待办、倒计时等组合。
- 照片信息带支持 EXIF GPS 坐标；照片编辑的信息带页可保存当前照片的地点备注。备注覆盖坐标，清空后恢复坐标。系统选择器可能移除 GPS；备注跟随导入后的本地照片文件，重新导入会创建新文件。
- 轮播图库支持缩小/隐藏预览，点选照片后展开大图。
- 通知增加 Android 16 ProgressStyle 和简短状态支持；缺失提升 API 时保留可用的进度样式。支持图片、文字分享及系统文字处理入口。
- 荣耀灵动胶囊和任意门推荐属于系统控制的展示入口：本版本提供标准通知、分享和文字处理兼容，未完成厂商专属认证接入，不能保证荣耀设备自动出现胶囊或任意门推荐。
