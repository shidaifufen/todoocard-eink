# 卡片版式规范（528×792 六色）

改任何模板之前先读这份。目标：**13 个模板共用同一套骨架**，字号放大不重叠、边界严格对齐、
白底上没有杂色噪点。

## 1. 画布与安全区

| 项 | 值 |
|---|---|
| 画布 | 528 × 792 |
| 安全边距 M | **32**（真机边框会吃掉 2~3mm，左右统一 32，不许再有 30/34 混用） |
| 可用区 | x: 32 ~ 496（宽 **464**），y: 32 ~ 760 |
| 栏网格 | 12 栏，`COL = 464/12 ≈ 38.67`，跨栏一律 `M + COL*n` |
| 基线网格 | 8px，纵向坐标优先落在 8 的倍数上 |

## 2. 纵向槽位（所有模板必须落在这几条线上）

| 槽位 | y | 用途 |
|---|---|---|
| `Y_HEAD` | 28 | 标题（30pt）顶部；左上红方块 13×13 画在 `(M, Y_HEAD+8)` |
| `Y_META` | 36 | 右上角小字（16pt） |
| `Y_RULE` | 88 | 页眉分隔线（需要的模板才画） |
| `Y_HERO` | 104 | 主视觉（大数字 / 大图 / 自定义积木）顶部 |
| `Y_BODY` | 272 | 正文起点 |
| `Y_BODY_END` | 676 | 正文终点，内容不得越过 |
| `Y_FOOT_RULE` | 700 | 页脚分隔线 |
| `Y_FOOT` | 716 | 页脚文字，行距 24，最多 2 行 + 右侧署名 |
| `Y_SAFE_BOTTOM` | 760 | 安全区下沿 |

## 3. 字号与行距

字号只有这些档（`FS`）：
`title 30 / meta 16 / hero 96 / hero_unit 38 / h2 20 / body 19 / small 16 / tiny 13`

行距：正文 24~28，小字 20~24。右对齐文字**先量宽再画**，右边缘固定 `CARD_W - M`。

### 字号缩放必须走 `P()`

网页上的字号滑块（100%~135%）改的是 `_SCALE`。**所有行距、块高、偏移都要过 `P(px)`**：

```python
y = Y_BODY
for row in rows:
    d.text((M, y), row.text, font=font("light", 24), fill=BLACK)
    y += P(40)          # ✅ 跟着字号一起长
```

直接写 `y += 40` 就是"字变大了但行距没变"，一定会压字——这是旧版卡片重叠的主因。

内容放不下时的做法：**先算高度再决定字号**（`_fit(need, avail)` 会把 `_SCALE` 临时降下来，
最低 0.85），不要"先画完再整体挪"。旧版的 `fit_content` / `distribute_vertical`
已经废弃成空实现，就是因为它们是画完再挪，会破坏节奏。

## 3.5 字号缩放的安全边界（100%~135%）

用户可以把字号调到 130%+，所以任何"贴边"都要按最大字号留余量，规则：

1. **槽位内元素**（页眉标题/日期/计数等）：用 P() 算位置，并留 P(6) 的内边距；
   放不下就降字号或不画，**绝不允许越出色块边界**（待办卡页眉是重灾区）。
2. **正文元素**：底边不得越过 Y_FOOT_RULE - P(2)；先算高度再决定画不画
   （自定义卡的积木是"放不下整块跳过"）。
3. **动态锚点要夹紧**：像"本月/全年点阵""今年还剩"这类跟着内容走的块，
   锚点用 min(设计值, Y_FOOT_RULE - 块高 - 余量) 往回收。
4. **横向先量后画**：同一行有多段文字（如口名 + 用电量）时，后一段的 x 必须由
   前一段实测宽度推出来，不能写死偏移。
5. 自检必须过：	ools\check_cards.py 会检查**压字**（文字包围盒两两求交）、
   **越槽位**（正文压页脚线 / 文字越出色块 / 越过安全区 / 出画布）、
   调色板外像素、安全区外墨迹；三档字号全部 0 问题才算过。

## 4. 颜色与抗锯齿（白底杂色噪点的根因）

六色只有 黑/白/黄/红/蓝/绿。上游 `payload.py` 会对整张图做 Floyd–Steinberg 抖动，
**只有"输入像素本来就在调色板里"时误差才为 0**。

PIL 画字、画圆时默认做抗锯齿，边缘会产生大量灰色中间值；这些灰值被抖动扩散后，
在真机白底上就是一层彩色麻点。所以所有模板出图前都要吸附调色板：

```python
return snap_palette(img)                                  # 纯文字/图形模板
return snap_palette(img, keep=[(0, 0, W, photo_h)])       # 有照片的，照片区保留继续抖动
```

`render_summary / weather / progress / todo / quote / poem / calendar / countdown / energy`
已由 `_snapped()` 自动加这一步；`render_ai / render_custom` 内部按 `keep` 区域处理；
照片卡的信息带在 `card.py` 里单独 `snap_palette`。

自检命令（会检查"调色板外像素"和"安全区外墨迹"）：

```bat
.venv\Scripts\python.exe tools\check_cards.py %TEMP%\card_check
```

要求：100% / 110% / 130% 三档字号下 **问题数 = 0**。
唯一例外：待办卡的黄色通栏页眉允许越出左右安全边距（top-band 白名单）。

## 6. 新加模板的检查清单

1. 页眉用 `_head()`，页脚用 `_foot()`，小节头用 `_section()`，进度条用 `_bar()`；
2. 所有纵向步进用 `P()`；
3. 正文不越过 `Y_BODY_END`，页脚只放 1~2 行；
4. 出图前 `snap_palette()`（有照片就传 `keep`）；
5. 跑一遍 `tools/check_cards.py`，三档字号问题数都得是 0；
6. 真机看一眼：白底有没有麻点、缩放后有没有压字。
