# Android 1.3.0 更新与 Web 功能核对

## 本次实现

- 默认联网获取内容；本地编辑内容由用户主动选择“手动内容”。首次打开自动获取每日总结天气，网络城市无需定位权限；可指定城市或恢复自动城市。网络城市可能受 VPN 影响。
- 每日一句接入一言 API，作者优先使用 from_who，缺失时使用来源作品，不使用投稿人冒充作者。每日诗词接入今日诗词 API，同步标题、朝代、作者、正文与译文；无译文时尝试在线赏析，支持独立刷新赏析。
- 句子、诗词分别记录最近 300 条，连续重复最多重取 6 次。Bing 优先提供近 8 天未看过的图片。服务无新内容时提示重试，不用本地模板冒充 API 新内容。
- 模板沿用 Web 的六色、红色标题标记和点阵结构；修正进度标签挤入条形图，诗词标题与署名分行，译注增加至 5 行，窄屏／横屏可滚动访问完整操作区。
- 系统相册按 MediaStore 目录列出并可加入整个目录；新增照片在重新读取相册时加入轮播。保留系统照片多选与 SAF 普通文件夹。部分照片授权仅能访问已授权部分；云相册未下载照片仍应使用系统选择器。
- 默认扫描仅显示 FF:FF 开头设备，无结果时显示“查找所有设备”。保留已保存设备优先选择。
- 计划从每 15 分钟轮询改为系统下一次闹钟；统一时间轴与执行时间计算，支持跨午夜与工作日／周末规则，同时间同模板合并，记录执行失败原因。
- 系统通知包含查找、连接、推送百分比、显影与结果；结束后约 5 秒清除。Android 16+ 请求系统实时活动提升，荣耀胶囊等具体形态由系统决定。
- 新增 Bing 壁纸与可配置的 AI 生图，复用照片裁切／调色；可选 API Key 使用 Android Keystore 加密。普通句子、诗词、天气、Bing 和免费赏析无需配置密钥。
- 倒计时按日历日计算，避免当天时分导致少算一天。

## Web 核对

| 功能 | Android 情况 |
| --- | --- |
| 每日总结、待办、日历、时间进度、倒计时 | 已有并修正版式／日期计算 |
| 每日一句、诗词与赏析 | 本次接入 API、自动更新、独立刷新与去重 |
| 天气看板、色块天气 | 本次补齐自动城市、湿度、体感、日出日落、穿衣参考 |
| 照片轮播、系统分享、裁切调色、杂色吸附 | 已有，本次增加系统相册目录 |
| Bing 与 AI 生图 | 本次加入；自有生图接口需要配置密钥 |
| 每日计划、间隔、时间轴、历史 | 本次统一调度并增加系统权限入口 |
| 自定义文字卡片 | 支持标题、分段文字与分享文字；桌面任意积木／二维码布局编辑器尚未完整移植 |
| 桌面收藏与跨端配置同步 | 尚未提供跨端同步；本次没有伪造桌面账号或服务连接 |
| 充电统计 | 依赖电脑端 port_history.db，没有手机侧数据源，未虚构统计 |

## 固定签名与升级

从本版起采用固定 release 签名，密钥已保存至 GitHub Repository Secrets，本机另有备份。CI 会检查固定证书 SHA-256，缺失或证书错误时停止构建。此前临时 debug 签名的私钥没有留存，旧安装可能需要最后一次卸载，此后的正式版本可覆盖升级。维护说明见 `android/SIGNING.md`。

## 验证与边界

使用 GitHub Actions 执行单元测试和 APK 构建，导出模板与长文本卡片预览；新增内容解析、作者归属、默认联网／去重、跨午夜、同时间规则合并测试。未修改 BleClient.kt、Payload.kt、QuickLz.kt。

到点表示开始获取内容与查找硬件，网络、卡片广播、BLE 传输和显影仍需时间。精确定时需用户开启系统“闹钟与提醒”，后台运行仍受系统省电策略约束。未完成本机荣耀真机验证，不能保证每个系统均显示胶囊。
