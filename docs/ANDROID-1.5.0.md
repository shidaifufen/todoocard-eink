# Android 1.5.0（2026-11-24）

- 新增独立 JSON 版式包，设置 → 外观中支持导入预览、应用、导出当前/默认、撤销、恢复内置。
- 两种天气看板的文字、色块、天气图标、温度折线与三天柱状图全部迁到独立配置。其余文字卡片可通过组件组合或原版式兼容元素覆盖。
- 通用渲染器提供文字、列表、色块、图标、图表和组合组件，支持动态数据绑定、六色、边界裁剪与长文字适配。
- 版式与内容、照片、设备、计划及 API 密钥分开保存；部分导入只覆盖指定模板。预览、手动推送与定时推送共用版式。
- 根据版式依赖更新在线内容，历史快照与重推保留当次图片。配置持久保存，应用升级仍保留。
- 保留固定签名及 BLE、面板映射、QuickLZ 实现。

使用和格式详见 [版式包说明](../layouts/README.md)。照片编辑器与新增系统能力仍由应用提供，新 API 或新组件需要更新引擎。
